# Crime Data Analysis & Prediction

## 📌 Project Overview
This project focuses on analyzing crime data from 2020 to the present to understand crime patterns, trends, and locations. Python is used for data cleaning, exploratory data analysis, and feature engineering to prepare the dataset for further crime analysis and machine learning.

## 🎯 Project Objectives
- Analyze crime patterns and trends.
- Identify areas with higher crime frequencies.
- Understand crime occurrences by year, month, day, and time.
- Explore victim age and other crime-related details.
- Prepare data for machine learning applications.

## 🛠️ Tools & Technologies
- **Python** – Data analysis and preprocessing
- **Pandas** – Data handling and cleaning
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Correlation heatmaps
- **Scikit-learn** – Feature encoding, scaling, and data preparation
- **Jupyter Notebook** – Project development

## 📂 Dataset Description
The dataset contains crime records with details such as:

- Crime report number
- Report date and occurrence date
- Crime code and crime description
- Area and area name
- Victim age and sex
- Weapon description
- Crime status
- Location, latitude, and longitude

**Dataset file:** `Crime_Data_from_2020_to_Present.csv`

## 🔍 Project Workflow

1. **Data Loading:** Imported the dataset using Pandas.
2. **Data Inspection:** Checked dataset shape, data types, missing values, and duplicate records.
3. **Data Cleaning:** Explored missing values, duplicate rows, and inconsistent data.
4. **Feature Engineering:** Extracted year, month, day, weekday, and hour-related features.
5. **Data Preprocessing:** Applied encoding and scaling techniques to selected columns.
6. **Exploratory Data Analysis:** Used descriptive statistics, box plots, scatter plots, and correlation heatmaps.
7. **Machine Learning Preparation:** Selected features and prepared the target variable for a classification task.

## 📊 Key Analysis Areas

- Crime frequency by area
